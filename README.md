# Arduino Traffic Light

My first Arduino electronics project, built using Tinkercad Circuits.

## What I built

A simple traffic light system using:
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- 3 resistors
- Breadboard

The LEDs turn on in sequence with timed delays.

## What I learned

- Basic Arduino programming
- Digital outputs
- LED circuits
- Resistors
- Breadboard connections
- Using Tinkercad to simulate electronics
